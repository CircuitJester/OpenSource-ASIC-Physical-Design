# ASIC Physical Design Projects

A hands-on portfolio of digital designs taken from RTL through synthesis and open-source ASIC physical implementation.

The projects use Yosys and OpenROAD-flow-scripts with the Nangate45 standard-cell technology to build practical experience with the RTL-to-GDS flow.

## Repository Scope

This repository focuses on understanding how synthesizable RTL becomes a physically implemented ASIC design.

The workflow covers:

RTL Design
-> Functional Verification
-> Logic Synthesis
-> Timing Constraints
-> Floorplanning
-> Power Distribution Network
-> Placement
-> Clock Tree Synthesis
-> Routing
-> Parasitic Extraction
-> Physical Verification
-> GDSII Generation
